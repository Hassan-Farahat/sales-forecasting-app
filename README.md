# 📈 Sales & Revenue Forecasting App

An interactive Time Series Analytics dashboard built with Python, Streamlit, and Scikit-Learn to project future business revenue.

🚀 **[Live Demo](https://hassan-farahat-sales-forecasting-app-app-jtdeib.streamlit.app/)**

## ✨ Features

* **Revenue Projections:** Predicts future monthly sales using linear trend regression.
* **Interactive Horizon Slider:** Adjust prediction timelines from 1 to 12 months in real time.
* **Clear KPI Metrics:** Calculates expected next-month revenue, average monthly growth rate, and total cumulative projections.
* **Visual Trend Line:** Interactive Plotly graph contrasting historical performance against expected future estimates.

## 🛠️ Tech Stack

* **Framework:** Streamlit
* **Machine Learning:** Scikit-Learn (`LinearRegression`)
* **Data & Visualization:** Pandas, NumPy, Plotly Express
